# Startup profile for Notch Island, hand-written rather than recorded: the island's own code is
# small, and all of it sits on a hot path — the overlay starts at boot and every tap morphs the
# island — so it is compiled ahead of time wholesale. Libraries ship their own profiles, which
# AGP merges with this one; profileinstaller applies the result to sideloaded installs too.
#
# H = hot, S = runs during startup, P = runs after startup. ** matches across packages.
